# Scheduling messages

Any message can be written now and sent later: a reminder timed for the evening, a morning check-in queued the night before, or follow-up instructions set for after an appointment.

## Scheduling a message

1. Write the message as usual.
2. Click the clock icon and choose **Schedule for later**.
3. An amber row appears with a date and time picker, labeled with your clinic's timezone. Pick when it should go out.
4. The send button becomes **Schedule Message**; click it.

The message appears in the thread as a bubble with an amber **Scheduled** badge showing exactly when it will send, both as a date and as "in X hours" style relative time.

## Changing your mind

A scheduled message stays editable until it sends:

- **Edit** reopens it in the composer under an "Editing a scheduled message" banner; save with **Update Scheduled**, or click **Send Now** to fire it immediately. **Discard** abandons your edits.
- **Cancel** deletes the scheduled send after a confirmation; it will not be sent.

Once the send time passes and the message goes out, it behaves like any other sent message and can no longer be edited or cancelled; the page tells you so if you try.

## Where it works

Scheduling is available in the Messages inbox and in the slide-over composer on patient, episode, and review pages, with the same controls in both places.
